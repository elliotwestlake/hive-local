## Fixed

- **ZHA on Home Assistant 2026.11 (zigpy 2.x):** setting a Hive thermostat to report its temperature every 120 s raised `AttributeError: 'ZCLAttributeDef' object has no attribute 'status'` after the thermostat accepted it. Hive Local then re-sent the setting at every temperature report. zigpy 2.x returns the result in a different shape; both shapes are handled now. ([#1](https://github.com/elliotwestlake/hive-local/issues/1))

Pre-release for testing. With this version you should see `Hive thermostat … now reports temperature at least every 120 s` in the log once, and the error shouldn't appear.
