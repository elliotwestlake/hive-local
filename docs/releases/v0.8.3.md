## Fixed

- **ZHA on Home Assistant 2026.11 (zigpy 2.x):** the fix from 0.7.1 is back. 0.8.0–0.8.2 were built without it, so the `AttributeError: 'ZCLAttributeDef' object has no attribute 'status'` came back, and Hive Local re-sent the thermostat's reporting setting at every temperature report. ([#1](https://github.com/elliotwestlake/hive-local/issues/1))

After updating you should see `Hive thermostat … now reports temperature at least every 120 s` in the log once, and the error shouldn't appear again.
